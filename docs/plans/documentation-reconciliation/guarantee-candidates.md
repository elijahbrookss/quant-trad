# Phase 1 Guarantee-Candidate Inventory

This is a discovery inventory for frozen baseline
`d46e40bf55caeea12f4ccbde640c71f271eaf9c4`. It is **not** the guarantee
registry and contains **zero active guarantees**. Static alignment is not a test
PASS. Every proof below has verification status `UNRUN` until Phase 2 creates a
commit-specific attestation.

The independent discovery axes are:

- source authority kind: normative contract, accepted ADR, implementation
  property, or synthesized candidate;
- source lifecycle: active, proposed, superseded, historical, or unclear;
- candidate activation: `unactivated` for every Phase 1 row;
- conformance: static-aligned, partial, contradicted, or unclear;
- proof maturity: named evidence, partial evidence, manual-only, or none;
- future Phase 2 disposition: enforced guarantee, partially enforced, candidate,
  implementation property, superseded, contradicted, or unclear.

No Phase 2 disposition has been assigned yet.
