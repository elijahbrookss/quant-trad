Intentional repetitions are not automatically duplicates: known-at/prefix
causality, provider-free reads, Dataset quality/admission, and reporting as a
projection recur at distinct ownership boundaries. Phase 3 should preserve one
authority and use boundary-specific links rather than flattening those
distinctions.

## Discovery Scope

This inventory exhaustively reviewed the platform contracts and agent guidance,
then classified the active data/provider, collection/archive, indicator,
decision, execution, BotLens, persistence/orchestration, reporting, deployment,
and validation vocabularies most likely to collide. Generic occurrences such as
`fact`, `run`, `report`, `evidence`, `ready`, `cursor`, and `fingerprint` were
treated as search leads rather than independent term rows. This is a
collision-focused inventory, not a catalog of every enum value, DTO field, CLI
noun, or implementation class. Phase 2 glossary work must resolve these
candidates before claiming normative terminology coverage.
